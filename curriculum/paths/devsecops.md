# DevSecOps Engineer path

For engineers who secure the path from a commit to a running pod. The path builds each control the way the tool that enforces it works: Linux capabilities and seccomp, RBAC and admission, a secrets service with leases, runtime detection over system calls, NetworkPolicy, secret scanning, SPIFFE workload identity, CVE prioritisation and a CIS benchmark, plus the supply chain in between (workflow security, OIDC, SBOMs, signing) and cloud IAM.

Lessons appear here as they are published; prerequisites are listed on each lesson page.
