# AIOps Engineer path

For engineers who already operate Kubernetes and cloud and want to put agents to work on them without handing over the keys. The path takes the primitives you need (a lab, how containers isolate work) and goes straight to the tool servers, guardrails, triage agents and evaluations that make agentic operations safe.

Lessons appear here as they are published; prerequisites are listed on each lesson page.
