# DevOps Engineer path

From a single Linux process to a GitOps-driven platform. This is the default path if you are not sure where to start: it follows the phases in order and skips lessons that only matter for a specialisation.

Lessons appear here as they are published. Each one is self-contained; prerequisites are listed on the lesson page and the tutor skills respect them.
